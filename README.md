# Mikrotik Monitoring

ابزار مانیتورینگ زنده‌ی چند-روتری میکروتیک از طریق RouterOS API.

## نصب

```bash
pip install -r requirements.txt
```

## آماده‌سازی هر روتر

```
/ip service enable api
/ip service enable ftp   # فقط اگر از قابلیت بکاپ‌گیری استفاده می‌کنید
```

## تنظیمات

فایل `config.json` را ویرایش کنید — بخش `routers` لیستی از همه‌ی شعبه‌هاست:

```json
"routers": [
  {
    "id": "branch1",
    "name": "Branch 1",
    "host": "192.168.88.1",
    "port": 8728,
    "username": "admin",
    "password": "YOUR_PASSWORD",
    "use_ssl": false
  }
]
```

## اجرا (نسخه‌ی وب — پیشنهادی، همه‌ی روترها هم‌زمان)

```bash
python web_main.py
```
سپس در مرورگر: `http://127.0.0.1:8080`

## اجرا (نسخه‌ی ترمینال — فقط یک روتر)

```bash
python main.py --router branch1
```

## قابلیت‌ها

- صفحه‌ی اصلی با دو مسیر جدا: **Monitoring** و **Router Backup**
- مانیتورینگ CPU/RAM/Disk/Voltage/Board Temperature
- ترافیک لحظه‌ای و تجمعی هر اینترفیس (مقاوم در برابر ریست روتر)، با دکمه‌ی ریست (کلی یا تک‌اینترفیسی)
- لیمیت ترافیک قابل‌تنظیم (بر اساس نام اینترفیس یا کلمه‌ی کلیدی در کامنت) + هشدار عبور از لیمیت
- کشف و مانیتورینگ خودکار تانل‌ها (EoIP/GRE/IPIP/WireGuard) بدون نیاز به تنظیم دستی
- وضعیت کامل DHCP (سرورها، پول‌ها، لیزهای فعال) + نوتیف اتصال دستگاه جدید
- بکاپ‌گیری با یک کلیک (`.backup` و `.rsc`)، **ذخیره‌ی دائمی روی سرور**، **تاریخچه‌ی کامل بکاپ‌ها**، و **زمان‌بند خودکار روزانه** (مثل یک تسک)
- چند-روتری با تب سوییچ بین شعبه‌ها
- نوتیفیکیشن toast در داشبورد وب
- سازگار با هر مدل/نسخه‌ی RouterOS — ویژگی‌های پشتیبانی‌نشده فقط خالی نمایش داده می‌شن، نه خطا

## ساختار پروژه

```
mikrotik-monitoring/
├── main.py                 # نقطه‌ی ورود نسخه‌ی ترمینال
├── web_main.py              # نقطه‌ی ورود نسخه‌ی وب (چند-روتری)
├── config.json               # تنظیمات
├── api/                        # ارتباط با RouterOS API + FTP
├── models/                      # ساختارهای داده
├── monitor/                      # منطق مانیتورینگ (ترافیک، لیمیت، تانل، DHCP، بکاپ)
├── utils/                          # فرمت‌دهی و نمایش ترمینال
└── web/                              # اپ Flask + داشبورد HTML/CSS/JS
```

## فایل‌ها و پوشه‌های تولیدی هنگام اجرا (پاک نشوند)

| مسیر | توضیح |
|---|---|
| `traffic_totals_<router_id>.json` | شمارنده‌ی تجمعی ترافیک هر روتر |
| `backups/<router_id>/...` | فایل‌های واقعی بکاپ ذخیره‌شده روی سرور |
| `backup_history.json` | تاریخچه‌ی همه‌ی بکاپ‌های گرفته‌شده (دستی و زمان‌بندی‌شده) |
| `backup_schedules.json` | زمان‌بندی بکاپ خودکار هر روتر |
